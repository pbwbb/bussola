# 🔎 Caso: Padaria Pão Nosso

> Simulação de treinamento. **Todos os dados são fictícios** — nomes, e-mails, IPs e empresas foram inventados para este exercício.

## Você é o novo analista do SOC

São **03:14 da manhã**. Um alerta acabou de chegar sobre a conta de um funcionário da **Padaria Pão Nosso**. Alguém pode ter invadido. Sua missão é descobrir o que aconteceu — usando só os arquivos deste repositório.

Comece pelo arquivo **`alerta.txt`**. Ele é o ponto de partida.

## Como investigar

- Abra cada arquivo e **leia com calma**.
- Sua melhor ferramenta é o **Ctrl+F** (buscar): procure por um nome, um horário, um IP.
- Compare as informações entre os arquivos. Uma pista de um arquivo se conecta com outra.
- Anote os horários — a ordem dos eventos conta a história.

## O que tem aqui

```
alerta.txt            → o alerta que começou tudo
emails/               → as mensagens que chegaram para a padaria
logs/                 → os registros dos sistemas
roteiro-do-aluno.md   → as perguntas que vão guiar a investigação
```

Abra o **`roteiro-do-aluno.md`** e vamos investigar juntos. 🚀
